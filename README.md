# Connector Factory free tools

Twenty free, MIT-licensed workflows for architecture, delivery, data, DevOps and
product work, from [Connector Factory](https://plugins.ascaidevlabs.com) (operated by
AscaiDevLabs). Each one is a set of written instructions, a checklist and a template
that guide your AI assistant through the job. No account, payment or server is needed:
your assistant does the work.

## Use in any AI assistant (no install)

1. Open the tool's page from the table below and choose **Copy instructions**, or open
   its `SKILL.md` in `plugins/<tool>/skills/<tool>/`.
2. In ChatGPT or Claude, create a Project and paste the instructions into the project
   instructions, so every chat in it uses the tool. Or paste them at the start of a chat.
3. Ask your question and add the details the tool asks for.

## Install in Codex

Download or clone this repository, then run from its directory:

```bash
codex plugin marketplace add .
```

Then use `/plugins` and install the tools you want. The marketplace appears as
**Andrew Cairns Free Plugins**. Start a new chat before using them. See
[OpenAI's plugin setup](https://developers.openai.com/plugins/build/plugins#install-a-local-plugin-manually).
