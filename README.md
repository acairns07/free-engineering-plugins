# Andrew Cairns Free Plugins

Independent skills-only workflows by Andrew Steven Cairns. No backend, payment,
external account or hosted LLM inference is required by these packages.

## Install locally

Download or clone this collection, then run from its directory:

```bash
codex plugin marketplace add .
```

Open Plugins in the ChatGPT desktop app, select **Andrew Cairns Free Plugins**,
and install the individual products you want. Start a new chat before using them.
Codex CLI also provides `/plugins` for configured marketplace sources. Availability
depends on the supported client and workspace settings. Local packages may be
marked Desktop only; this export does not promise web/mobile installation.

See [OpenAI's marketplace setup](https://developers.openai.com/plugins/build/plugins#install-a-local-plugin-manually).
