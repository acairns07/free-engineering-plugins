# FinOps Estimator

Estimate cloud spend from workload units, supplied prices and explicit uncertainty.

## Activation

Comparing architecture options or sizing expected cloud consumption.

## Package contents

- `skills/finops-estimator/SKILL.md` workflow and safety contract
- Domain checklist, example activation and output template

Skills-only; no backend, hosted inference or publishing action.
