# PRD Factory

Create evidence-linked product requirements, bounded scope, acceptance criteria and delivery questions from an idea or existing brief.

This independent skills-only plugin requires no MCP backend and sends no data to the platform operator. ChatGPT/Codex processes supplied content under the host service terms. The files contain an original general workflow, reference, template and worked example.

Version 1.0.0. Structural development package; the declared publisher identity, listing URLs and country targeting must be verified before submission. Public support: `ascaidevlabs@gmail.com`. The publisher sign-in account is separate from customer support. No claim of completed host activation testing.
